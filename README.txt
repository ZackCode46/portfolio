## Projects

### Smart Drone Farm

**Smart Drone Farm** is a farming automation game inspired by the concept of *The Farmer Was Replaced*.

The game combines farming simulation, drone automation, and programming logic. Players control drones to plant, water, grow, and harvest crops while managing resources and expanding their farm.

The project was created as an exploration of how programming and automation concepts can be implemented into a game environment.

#### Features

- Drone movement and control
- Planting system
- Crop growth system
- Watering system
- Harvesting system
- Multiple crop types
- Coin and economy system
- Shop system
- Farm expansion
- Multiple drones
- Drone upgrades
- Simulation speed control
- Automation-based gameplay

#### Current Crops

- Wheat
- Carrot

Each crop has different growth times and values, requiring the player to manage the farm efficiently.

#### Automation Concepts

The gameplay focuses on several programming and automation concepts:

- Algorithms
- Conditional logic
- Loops
- Automation
- Resource management
- Optimization
- Drone control

#### Technology

- HTML
- CSS
- JavaScript
- HTML Canvas

#### Release

**Version:** `v1.0.0`

**Status:** First Release

This is the first public release of Smart Drone Farm. Future updates may introduce additional crops, automation tools, drone programming, farm layouts, challenges, sound effects, and other gameplay improvements.

> Inspired by the automation concept of *The Farmer Was Replaced*, while being developed as an independent project with its own implementation and gameplay systems.

### SmartTech Garden

SmartTech Garden is an IoT-based smart farming system designed to monitor and control environmental conditions in a plant-growing environment.

The system integrates sensors, actuators, a microcontroller, and a web interface to provide monitoring and automation.

#### Hardware

- ESP32
- DHT22
- Soil moisture sensor
- BH1750
- DS3231 RTC
- Relay module
- Water pump
- LCD display

#### Features

- Soil moisture monitoring
- Temperature and humidity monitoring
- Light monitoring
- Automatic watering
- Manual watering
- Pump control
- Sensor history
- Scheduling
- Web-based monitoring
- IoT control

#### Technology

- ESP32
- Arduino
- Firebase
- JavaScript
- HTML
- CSS
